# 📸 Galería Fotográfica de los Ensayos Experimentales

Este directorio contiene el registro fotográfico tomado durante las campañas de medición en exteriores para el proyecto **ORR** en la provincia de San Juan, Argentina.

Las imágenes están organizadas en dos carpetas según el entorno físico del experimento:
1. **Bajo Follaje de Olivos (`fotos/campo/`):** Ensayos con severa obstrucción de biomasa frutal.
2. **Espacio Abierto (`fotos/libre/`):** Canal de calibración en línea de vista despejada.

---

## 🌳 Experimento: Bajo Follaje de Olivos (Campo)

Mediciones realizadas dentro de una plantación intensiva de olivos. La antena y el módem se posicionaron bajo el follaje denso para evaluar la difracción y atenuación de la banda en VHF/UHF frente a la biomasa húmeda.
